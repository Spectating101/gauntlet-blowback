# Blowback

**Gauntlet entry automation for finished projects.**

Blowback is a local-first, Playwright-driven submission operator for competitions, grants, hackathons, conferences, fellowships, and other external-validation routes.

Its job is deliberately narrow: turn canonical project/profile data plus an opportunity manifest into a prepared portal entry, then stop at explicit human gates for identity-sensitive or irreversible actions.

> Discover/choose elsewhere → compile the entry packet → prepare the portal → human review → submit.

The project is being initialized on a development branch. See the first implementation PR for the executable contract and safety boundaries.
