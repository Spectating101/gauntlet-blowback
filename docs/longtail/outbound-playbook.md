# Manufactured Conversion Playbook

Published calls are only half of Blowback. Mature assets should also generate opportunities directly.

Amounts below are **test asks**, not proven market prices. They exist to create measurable market feedback.

## Cite-Agent

### Researcher evaluation pilot
- Target: labs / research groups / evidence-heavy teams.
- Ask: NT$5k–20k.
- Scope: 2–4 week bounded evaluation using the live product.
- Deliverables: onboarding, defined workflow, usage/feedback capture, short findings report.
- Success evidence: paid invoice, completed researcher workflow, testimonial/continued-use request.
- First ask should be small enough that a PI/lab can approve without procurement theater.

### Lab deployment / support pilot
- Target: university labs.
- Ask: NT$10k–50k.
- Scope: setup + onboarding + support window around existing product.
- Do not promise custom enterprise development inside the pilot price.

## YZU / Research Drive expertise

### Institutional workflow diagnostic
- Target: university research centers / labs with fragmented data + literature workflows.
- Ask: NT$5k–30k.
- Scope: workflow mapping, diagnostic, demo of proven YZU patterns, bounded recommendation memo.
- The product being sold initially is expertise/case-study-backed diagnosis, not a cloned university platform.

## Policy Lab

### Evidence / evaluation sprint
- Target: NGOs, policy teams, think tanks, research organizations.
- Ask: NT$5k–30k.
- Scope: one bounded empirical/evidence question, agreed inputs, reproducible analysis, short memo.
- Never imply causal certainty beyond the design.

## Nocturnal Oversight

### Cold review -> paid bounded pilot
- Target: newsrooms, watchdogs, civic research groups, archival/public-memory teams.
- Stage 1: free or low-cost cold comprehension review.
- Stage 2 ask: NT$5k–20k for an operational monitoring workflow.
- Trigger for paid stage: outside actor demonstrates real need and understands the system.
- Do not continue engineering merely because cold reviewers suggest speculative features.

## Hardware Splicer

### Industrial inspection / verification PoC
- Target: electronics/EMS/QA/manufacturing SMEs and labs.
- Ask: NT$10k–50k.
- Scope: exactly one inspection/verification problem.
- Required acceptance criteria:
  - defined inputs;
  - defined target output;
  - measurable error/success criterion;
  - preserved evidence artifact;
  - explicit boundary between model proposal, deterministic constraint and physical/bench evidence.
- Avoid generic “AI vision platform” proposals.

## Public-Good Control

### Shadow -> paid coordination pilot
- Target: competent NGO / civic / animal-welfare / disaster / redistribution operator.
- Ask: NT$5k–30k for bounded paid phase.
- First phase may be a shadow run on historical/live workflow.
- Success evidence: operator time saved, routing/coordination quality, correction burden, adoption decision.

## Refinery / Commons

### Evidence audit
- Target: OSS maintainers / research-infrastructure projects.
- Ask: NT$5k–20k.
- Deliverable: Capability -> Implementation -> Claim/evidence audit, unresolved claim list, recommendation packet.
- This campaign doubles as external validation of Commons itself.

## Citation Engine

### Integration / authority review
- Target: AI-agent / MCP / research-software infrastructure projects.
- Ask: NT$5k–30k.
- Deliverable: evidence-authority review, bounded integration prototype or architecture recommendation.
- Best targets are teams already publishing provenance, traceability, grounding or agent-governance pain.

## Sharpe Terminus

### Research-engineering / reproducibility audit
- Target: quant / data / finance research teams.
- Ask: NT$5k–30k.
- Deliverable: workflow/reproducibility/risk-control audit.
- Never pitch promised alpha or a “winning trading strategy.”

## Target-account campaign schema

Every outbound target should capture:

- actor / organization;
- why they plausibly care;
- observed pain signal and source;
- best matching asset;
- one truthful value proposition;
- one bounded ask;
- proposed price / support level;
- decision-maker / contact channel;
- packet version;
- human-send gate;
- sent receipt;
- response;
- meeting;
- pilot / contract / rejection;
- cash / adoption / validation outcome.

## Volume rule

Outbound should not wait for “perfect dream customers.”

For each mature asset:

1. generate 25 plausible target accounts;
2. eliminate obvious non-fit automatically;
3. prepare 10 high-quality bounded asks;
4. human-review and send the best 5–10;
5. measure response rate and meeting rate;
6. update target profile from evidence;
7. repeat.

The unit of learning is the target-account cohort, not one emotionally important conversation.

## Human gate

Blowback may research, prepare, personalize, validate and queue outbound. It must preserve the existing human gate before consequential final sends, commitments, payment, legal/IP acceptance or final submission.
