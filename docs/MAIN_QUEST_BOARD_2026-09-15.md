## Doctrine

1. **Thesis completion remains P0 execution work.** No application campaign may destabilize the MSc proposal/defense path.
2. **Main Quest A = funded PhD option creation.** Build several credible northern-Taiwan options rather than treating NYCU IAIS as the only route.
3. **Main Quest B = serious full-time / research-employment price discovery.** Fire a small number of high-fit roles now, before graduation, to create real comparison data against PhD funding/opportunity cost.
4. **Gauntlet side quests remain secondary.** Fellowships, competitions, grants, credits, conferences and pilots enter only when deadlines or expected value justify displacement of Main Quest work.
5. Reuse one canonical applicant dossier. Fork positioning by program/role; do not rewrite identity from scratch for every route.
6. General project development is allowed only when it closes a named Main Quest evidence gap or a hard-deadline side quest.
