# Anthropic AI for Science — Hardware-Splicer wake gate

Date: 2026-09-23  
Route: `anthropic-ai-for-science-general-2026`  
State: **research-only / evidence and consent gated**

## Current program facts

Current Anthropic material supports a broader AI for Science program beyond biology. The August 27, 2026 expansion announcement says any researcher may apply and advertises up to US$50,000 in credits per project.

Anthropic's Help Center still states up to US$20,000 in API credits for a six-month period.

Do not silently resolve this discrepancy in favor of the larger number. The live application/current terms must establish the actual available amount before a budget is submitted.

Current official rules also establish that:

- an individual applicant must meet the age-of-majority requirement;
- a researcher affiliated with a university/research institution must have all institutional consents necessary to participate;
- credits are placed on the organization identified in the application.

## Why HS is not ready to fire yet

The scientific proposal should be based on a real experiment, not on a large credit ceiling.

Hardware-Splicer must first have:

1. one real revision-bound physical result or preserved failure from #105;
2. at least one frozen artifact-backed Claude/API experiment that shows what Claude actually does in the protocol;
3. a defined scientific question and workload;
4. clear rights to the hardware/corpus/data submitted to Claude;
5. required institutional consent;
6. a receiving Anthropic organization/account.

## Preferred scientific question

A defensible question after #105 is:

> Can a general-purpose AI agent accelerate bounded hardware-engineering experiments while an independent evidence/authority layer prevents unsupported model outputs from acquiring physical authority?

The study should separate:

- model reasoning quality;
- deterministic engineering constraints;
- physical evidence;
- authority refusal/escalation;
- stale-evidence behavior;
- human intervention.

## Physical wake condition

Preferred trigger:

- #105 has a real physical board identity;
- `simulated:false`;
- cold/power evidence is bound to the exact subject;
- the bounded functional experiment has either produced a real result or preserved a real failure.

A negative physical result is acceptable. It may produce a stronger experimental question than a clean pass.

## Claude workload gate

Before requesting credits, freeze a workload such as:

- N model configurations;
- M repeated/frozen hardware cases;
- exact prompt/tool protocol;
- maximum tool calls per run;
- expected input/output token envelope;
- retry policy;
- adjudication runs;
- sensitivity/cross-model comparisons if scientifically justified.

Estimate credits from that workload and current API pricing/terms. Do not request the advertised maximum by default.

## Institutional/account gate

Before submission:

- determine whether application is made as an individual YZU-affiliated researcher or through an explicitly approved research group;
- obtain any required YZU/adviser/institutional consent;
- identify the Anthropic organization ID/account that would receive credits;
- document who controls billing, usage and collaborators;
- review publicity/interview/research-participation terms.

## Data/IP gate

Document separately:

- public/open hardware materials;
- Hardware-Splicer-owned code/evidence;
- any professor/RA data;
- any industry/provider materials;
- unpublished measurements;
- provider-returned reports/captures.

Only include data in Claude workflows when the right to do so is explicit.

## Fire condition

Move beyond `RESEARCH_ONLY` only when all of the following are true:

- substantive physical or equivalent scientific evidence exists;
- Claude workload is frozen enough to budget;
- required institutional consent is obtained;
- receiving organization/account is fixed;
- data/IP boundary is clear;
- current credit-cap/application terms are rechecked.

The program should fund a defined scientific experiment, not become a reason to manufacture extra HS scope.
