# Gauntlet Gate Audit — 2026-08-26

Status: **CANONICAL AUDIT OVERLAY** for the current long-tail and post-graduation campaign boards.

This document records the 2026-08-26 full audit of the active Gauntlet campaign universe against the current active portfolio, known project evidence, and live opportunity requirements reviewed during the audit.

It exists to prevent a recurring failure mode: treating every stored `FIRE`, `VERIFY`, or `HOLD` label as equivalent even when the unresolved condition is fundamentally different.

Until the machine-readable campaign records are reconciled, **this audit overrides stale campaign labels where the two conflict**.

## 1. Gate taxonomy

Every campaign should identify the strongest unresolved gate. Do not use generic `GATED` when a more specific class is available.

| Gate | Name | Meaning | Default handling |
|---|---|---|---|
| `G0` | Owner / portal | login, identity, consent, final submit, payment/travel choice | no product-readiness penalty; prepare everything else |
| `G1` | Eligibility / administration | student status, adviser/team rule, unpublished-paper rule, company requirement | verify once; FIRE if true, KILL if false |
| `G2` | Packet / application | CV, proposal, screenshots, 3-minute video, abstract adaptation | automate/reuse; normally cheap |
| `G3` | Integration / domain adaptation | sponsor SDK, named dataset, domain-specific model, bounded adapter | real engineering; must earn its cost |
| `G4` | External evidence | physical proof, independent operator, external user, partner, forward performance, adoption | cannot be generated by better writing; wait for reality |
| `G5` | Hard blocker / mismatch | degree, language, publication conflict, wrong domain, impossible rule | KILL unless the underlying fact changes |
| `G6` | Economics / optionality | time commitment, travel, compensation, IP/moonlighting, outside-work rules | application can still FIRE; acceptance waits for due diligence |

### Gate doctrine

- `G0/G1/G2`: clear aggressively.
- `G3`: only perform if expected conversion justifies the engineering.
- `G4`: do not substitute synthetic evidence, internal review, or marketing copy.
- `G5`: kill rather than contort an asset.
- `G6`: separate **application decision** from **acceptance decision**.

- verified FIRE count;
