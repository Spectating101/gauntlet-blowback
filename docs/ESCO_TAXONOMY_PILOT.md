# ESCO occupations discovery (pilot)

Run `npm run radar:esco -- 'research engineer'`. This queries the official ESCO searchable occupation vocabulary and returns bounded, read-only **occupation labels/URIs**.

**Taxonomy matches are not live vacancies, evidence of a hiring organization's requirements, credentials, eligibility, skill proficiency, an application, or an interview.** Never convert a record into a job opportunity or submission without a separately verified employer vacancy. This pilot does not modify the application funnel or write credentials.

Official API: https://esco.ec.europa.eu/en/use-esco/use-esco-services-api/esco-web-service-api . Check ESCO attribution/licence terms before redistributing ontology records; this pilot returns only short search results and URIs.
