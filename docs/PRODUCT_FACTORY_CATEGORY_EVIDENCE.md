# Product Factory category-evidence ladder

Gauntlet now treats Hardware Splicer's broader physical-transformation category as an empirical claim, not a narrative upgrade.

```text
L0  architecture/contracts only
L1  one revision-bound physical transformation with realized COGS
L2  >=3 physical runs across >=2 source modes
L3  L2 + >=2 benchmarked paid/customer-bound outcomes
```

The source modes may include `NEW_BUILD`, `MODIFY_EXISTING`, `MODULE_REUSE`, `DONOR_RETROFIT`, or `HYBRID`.

Even L3 does **not** automatically prove a moat or authorize investment/sale. It only permits a stronger portfolio repricing review based on real evidence.

This prevents:
- PF-002/PF-003 paper contracts from being counted as physical proof;
- three clean-sheet boards from being described as heterogeneous transformation generality;
- an unbenchmarked transaction from being counted as repeatable commercial evidence.
