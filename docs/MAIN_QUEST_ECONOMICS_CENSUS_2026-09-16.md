# Main Quest Economics Census — 2026-09-16

The Main Quest money layer is a **census**, not a shortlist.

## Rule

> Enumerate money for every route before using money to rank any route.

No PhD or job disappears because its economics are low, awkward, unknown, conditional, negotiable, or unpublished.

The coverage target is **149/149 Main Quest routes**:

- 61 PhD routes;
- 88 employment/research-employment routes.

Every route must ultimately carry an economics state such as:

- `VERIFIED_NUMERIC`
- `PUBLISHED_NONCASH`
- `NEGOTIABLE_UNDISCLOSED`
- `CONDITIONAL_PROGRAM`
- `HISTORICAL_REVERIFY`
- `SEARCH_PENDING`
- `IDENTITY_GAP`

Unknown is a result, not an omission.

## Execution order

`FULL ROUTE UNIVERSE → ECONOMICS STATE FOR EVERY ROUTE → VERIFY AMOUNT/CERTAINTY/COSTS → THEN RANK`
