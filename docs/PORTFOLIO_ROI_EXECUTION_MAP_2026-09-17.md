## ROI model

The priority index is an ordinal planning aid, not a financial expected value or acceptance probability.

```text
priority = 2 × upside + native fit + package reuse + current readiness
           + deadline leverage − remaining effort − 2 × external-dependency burden
```

Each component is scored on a small bounded scale from current evidence. Hard gates still override the index: an unavailable teammate, referee, adviser, partner, required payment, false claim, or prohibited AI-authorship rule cannot be compensated for by a high score.

Scales: upside, fit, reuse and readiness are 0-5; deadline leverage is 0-2; effort is 1-5; external-dependency burden is 0-3.
