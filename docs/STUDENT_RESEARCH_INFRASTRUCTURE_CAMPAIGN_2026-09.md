# Student infrastructure + research-credit campaign — 2026-09

## Purpose

Treat student entitlements, research API/compute credits, research previews, and PI-sponsored cloud awards as a first-class Gauntlet conversion lane.

These routes are not scored by headline face value alone. The realized value is the spend they actually displace or the experiment/infrastructure they make possible.

```text
student / institutional entitlement
        -> activate while eligible
        -> record activation + expiration
        -> route only permitted workloads onto it
        -> record actual displaced spend

research credit / preview
        -> verify research eligibility and use restrictions
        -> reuse one canonical research package
        -> prepare application
        -> human-gated submit where required
        -> record award / rejection / credit expiry

PI-sponsored resource
        -> build PI packet
        -> human PI review / consent
        -> PI or institution submits
        -> record award and institutional terms
```

## PI packet doctrine

The goal is to make a suitable professor's marginal effort approximately:

> review -> correct -> approve -> submit/sign

Maintain once:
- 2-page academic CV;
- 1-page technical CV;
- affiliation/student proof;
- 50 / 100 / 200-word bios;
- publication/preprint list;
- repository/demo index;
- preliminary results;
- architecture figures;
- research/data-ethics statement;
- milestone plan;
- cloud/API cost models;
- provider-specific answer bank;
- explicit list of claims that remain unproven.

Never fabricate PI involvement or represent institutional consent before it exists.

## Infrastructure routing after DigitalOcean

Use resources according to their actual terms, not as interchangeable coupons:

- Appwrite Education -> educational/noncommercial managed backend/auth/storage/functions;
- Heroku Student -> small eligible APIs/workers/data services;
- Azure Student -> arbitrary student/research cloud workloads within account terms;
- YZU resources -> licensed academic/research software and databases;
- Google / Oracle / AWS research credits -> formal research workloads if awarded;
- OpenAI / Anthropic credits -> experiments/inference, not general hosting.

A paid pilot must move off any entitlement that prohibits commercial use.

## Truth / accounting rules

- Credits are not cash.
- Nominal credits do not enter realized value until they displace intended spend.
- Noncommercial/research-only restrictions follow the workload.
- A PI-dependent route cannot become READY because the applicant packet is complete; the PI/institutional dependency must actually clear.
- A rolling route receives a refresh cadence, not a fabricated deadline.
- Research preview access is external validation but not revenue.
