# Hardware-Splicer Human Gates

The automation package should reduce the project owner's involvement to actions that cannot be delegated truthfully or safely.

## Human gates

- portal login, 2FA, or CAPTCHA;
- legal identity and eligibility attestations;
- originality/authorship attestations;
- adviser confirmation when a venue requires one;
- payment or travel authorization;
- secure model credentials;
- real physical bench actions/evidence;
- final submit.

## Not human gates

The owner should not need to decide or rewrite:

- which prepared project title to use;
- standard project description;
- innovation/technical contribution copy;
- evidence limitations;
- deck/paper source;
- route FIRE/HOLD/KILL state when eligibility and cost rules already determine it;
- ordinary upload mapping after portal inspection.
