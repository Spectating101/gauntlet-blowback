# Demo Script

## 30-second judge version

1. Open the Edition preview on **Global**.
2. Say: “These are finite material developments, not an infinite article feed.”
3. Open one story.
4. Point to **Current documented state** and **Before → Now**.
5. Switch quickly through **Timeline → Sources → Impact**.
6. Close: “Refinery reduces the reporting stream; Nocturnal preserves evidence and what changed; Edition makes that persistent state usable. The next test is a bounded real corpus and external users.”

Do not explain the implementation unless asked.

## 3-minute competition / funder demo

### 0:00–0:30 — problem

“Public reporting is abundant, but long-running events are fragmented across separate updates, corrections and sources. Search retrieves pages; it does not maintain a current documented state.”

### 0:30–1:10 — reader result

Open Edition Global.

- identify the lead and finite edition;
- show that Global is impact scope, not merely origin geography;
- open a living story;
- show Current State and Before → Now.

### 1:10–1:45 — inspectability

Move through:

- Timeline — how the state changed;
- Sources — what the coverage/evidence landscape looks like;
- Impact — where consequences are projected.

State explicitly: impact/presentation is derived. It cannot rewrite canonical evidence.

### 1:45–2:25 — architecture

Use one diagram:

```text
reporting / records
      ↓
Refinery — normalize / cluster / source roles
      ↓
Nocturnal — evidence / matter state / corrections
      ↓
Edition — finite human-facing projection
```

Mention that Nocturnal 1.2 is already engineering-frozen and passed its synthetic release gates, while Refinery preserves both positive and negative empirical outcomes.

### 2:25–3:00 — ask

Tailor the closing transaction:

- grant: fund/host a bounded pilot or open infrastructure tranche;
- research venue: evaluate the empirical mechanism/tool;
- lab/job: evaluate the demonstrated research-engineering capability;
- fellowship: use the stack as the concrete substrate for a narrowly scoped research question.

Finish with the missing proof: real corpus, real users, measured comprehension/stewardship and genuine correction handling.

## 8-minute technical version

1. **1 min — problem and non-claim**: fragmented changing information; not a truth detector and not an original newsroom.
2. **1.5 min — Refinery**: event/source-role reduction, exact-subject evidence, negative + positive build-vs-reuse controls.
3. **2 min — Nocturnal**: evidence grades, identity ambiguity, matter history, corrections, public/intake/operator boundary, snapshots, 5k/50k gates.
4. **2 min — Edition**: Global/Region/Country, finite edition, story dossier, presentation/media contracts, fail-closed unclassified state.
5. **1 min — reproducibility / deployment**: frozen release branches, public-review surfaces, deterministic artifacts.
6. **0.5 min — empirical next step**: bounded real pilot and measured tasks.

## Demo rules

- Never show synthetic fixture as if it were current news; keep the synthetic marker visible.
- Never say “AI decides truth.”
- Never imply Edition owns original reporting.
- Never spend the first minute in architecture diagrams when a visual reviewer surface is available.
- If a venue is Refinery-led, do not let Edition aesthetics obscure the actual empirical contribution.
