# Pilot Evidence Plan — conversion proof for the Gauntlet

The stack is product-complete enough that the next high-value work is evidence generation.

## Pilot scope

Start with a bounded **Global + ASEAN + Indonesia** corpus across multiple story morphologies (policy, company/market, disaster/environment, conflict/security, long-running public matter). Do not start with unrestricted world ingestion.

## Required pipeline accounting

Record the real compression chain:

```text
raw observations
  → deduplicated / normalized observations
  → event clusters
  → events admitted to Nocturnal
  → material matter-state changes
  → Edition candidates
  → Edition placements
```

For each stage report counts, processing latency, model/compute cost where measurable, and rejection/unknown rates. Do not substitute illustrative numbers.

## Correctness sample

For a predeclared sample of matters, an external evaluator should score:

- current documented state accuracy;
- whether Before → Now identifies the material change;
- source/provenance traceability;
- allegation / denial / correction / outcome separation;
- identity resolution and ambiguity handling;
- whether derived scope/impact has a visible rationale;
- whether modelled/hypothesis propagation is distinguishable from observed evidence;
- whether a genuine correction propagates without erasing history.

## Reader-task benchmark

Compare Edition with ordinary web/news search on tasks such as:

1. “What is currently documented?”
2. “What materially changed in the last week?”
3. “Which claims remain disputed?”
4. “What was corrected or superseded?”
5. “Why is this considered Global / regional / country-level?”
6. “Show me the primary/strongest available evidence.”

Measure:

- time to satisfactory answer;
- factual omissions/errors;
- number of pages/sources opened;
- ability to identify unresolved state;
- self-reported confidence only as a secondary metric.

## Stewardship benchmark

Measure:

- review minutes per 1,000 records/modules;
- ambiguous-identity review rate;
- correction/dispute queue volume;
- percentage of observations rejected or collapsed before expensive reasoning;
- percentage of events requiring human intervention;
- source-rights/media-review burden.

## Media/rights gate

Every public visual must carry the media-contract fields needed to determine provenance and `public_display`. No pilot result should depend on silently copying arbitrary publisher media.

## Success evidence for Gauntlet reuse

A useful first pilot does not need to prove global PMF. It should produce:

- one bounded approved real corpus;
- at least several external users completing real tasks without maintainer handholding;
- repeat use from at least some users;
- one real correction handled end-to-end;
- measured compression and cost data;
- measured stewardship burden;
- a task-comparison result against ordinary search/news;
- a written outside-evaluator report with failure modes.

Those outputs can then upgrade multiple Gauntlet routes at once: TWNIC/DPG/public-interest funding, research-software claims, lab/PhD evidence and future sponsorship/outbound.
