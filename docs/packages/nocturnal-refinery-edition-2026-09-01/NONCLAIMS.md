# Non-Claims / Submission Guardrails

These statements are prohibited unless later evidence changes the project state.

## Nocturnal / Edition

Do **not** claim:

- Nocturnal is a truth detector, guilt engine, or automatic attribution system.
- Co-appearance or recurrence proves a relationship or culpability.
- Edition performs original reporting or replaces journalists/reporting institutions.
- The current 50k release benchmark proves 50,000 fully AI-analyzed news articles per day.
- The stack has global-scale production readiness.
- Real-user adoption, repeat use, time savings or newsroom integration has been established.
- Source-rights/legal clearance exists for arbitrary real-world media or unrestricted real-person publication.
- A presentation score, impact scope or propagation edge is canonical evidence.
- An inferred/modelled/hypothesis edge is an observed causal fact.
- The current working masthead `EDITION` is a final public brand.

## Refinery

Do **not** claim:

- Reuse is always superior to rebuilding.
- The PSL experiment proves general economic value, price, demand or PMF.
- Evidence about one artifact/implementation verifies a sibling implementation.
- `verified`, `deployed`, `adopted`, `recommended`, `valuable`, `public` and `reusable` are interchangeable states.
- Public availability implies reuse rights.
- The deployed reviewer surface proves cold-human comprehension or adoption.

## Gauntlet / opportunity state

Do **not** claim:

- a route is eligible because the project fits thematically;
- a future/rolling deadline that has not been verified;
- a partner, institutional host, adviser, journalist applicant or public community that does not exist;
- salary/funding/visa/IP terms that the current source does not state;
- that a low application cost makes a full-time fellowship/residency/job cheap to accept;
- that one project layer is an independent external accomplishment merely because it lives in a separate repo or UI.

## Allowed strong claims

Strong claims are encouraged when bounded:

- Nocturnal 1.2 is engineering-frozen and technically pilot-ready for bounded evaluation.
- Its canonical release includes reproducible 5k/50k scale gates and a 15/15 fictional evaluator gauntlet.
- Edition RC1 is a deployed public-review reader surface with authority-separated presentation/media contracts.
- Refinery has both a negative generic reuse control and one bounded licensed curated-state result with a +50 percentage-point correctness difference.
- The stack has a coherent end-to-end architecture from observation abundance to persistent documented state to interactive human-facing presentation.

The credibility advantage comes from saying **exactly what is proven and stopping there**.
